# Phrasebook for exercise instructions (EN to RO)

Every translator uses these exact Romanian sentences, so 881 exercises read as one library, not eight.

## Voice

Write the way a good Romanian coach explains a movement to a client standing next to them: second person singular ("tu"), imperative, short sentences, everyday words. Never "dumneavoastră". Translate the meaning, not the words: reorder, merge or split sentences inside a step when Romanian reads better, but never add or drop an instruction. Read each step aloud; if it sounds like a subtitle, rewrite it.

## Hard rules

1. **Same steps.** The English steps are separated by a blank line. Keep exactly the same number of steps, in the same order, separated by exactly one blank line (`\n\n`). The mobile app shows one step per paragraph.
2. **No dashes as punctuation.** No em dash, no en dash, no spaced hyphen between words. Use a comma, a period, a colon or parentheses. Ranges: "8 până la 12", or "8 la 12". Hyphens inside words are fine (kettlebell-uri, într-un, s-o, dă-ți).
3. **Diacritics with comma below:** ș ț (never ş ţ), plus ă â î.
4. **Metric units.** Convert imperial units to rounded metric: 1 inch ≈ 2,5 cm ("6 inches" → "15 cm", "a few inches" → "câțiva centimetri"), 1 foot ≈ 30 cm ("2-3 feet" → "60 până la 90 cm"), 1 yard ≈ 1 m, 1 mile ≈ 1,6 km, 1 lb ≈ 0,45 kg ("45 lb plate" → "disc de 20 kg"). Decimal comma. "feet" as body part is "picioare" or "tălpi" ("feet flat on the floor" → "tălpile pe podea").
5. **Gym words come from glossary.md.** Barbell is "bara" (never haltera), cable is "scripete", lat pulldown machine is "helcometru", dumbbells "gantere" / "gantera", plate "disc", bench "bancă", rack "rack". Muscles: piept, umeri, triceps, biceps, antebrațe, dorsali, trapez, mijlocul spatelui, zona lombară (lombari), abdomen, oblici, fesieri, cvadricepși, femurali, gambe, adductori, abductori.
6. **Romanian quotes** „ ” if you ever quote something.
